# Account Setup Flow

An interactive multi-step account setup UI — a coded experiment in onboarding experience design.

---

## Overview

This project brings a common product pattern to life in code: the account creation flow. The focus was on making each step feel lightweight and guided, reducing friction while maintaining visual clarity.

Built as part of my playground — a collection of UI experiments where I translate design ideas into working interfaces.

## Built With

- **React** — component structure and step state management
- **Vite** — build tooling
- **JavaScript** — interaction and flow logic

## What I Was Exploring

- Multi-step form state management without a library
- Smooth transitions between setup steps
- Designing onboarding flows that feel fast, not tedious

## Run Locally

```bash
npm install
npm run dev
```
